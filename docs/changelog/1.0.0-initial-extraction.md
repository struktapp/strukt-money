# 1.0.0 — Initial extraction from Strukt Commons

**Date:** 2026-11-12

**Added**

- New `strukt/money` package under `strukt4/money`.
- Package metadata, README, license, PHPUnit/Pest configuration, and changelog.
- `Money::clone()` to preserve the cloning convenience previously inherited
  from `Strukt\ValueObject`.

**Changed**

- `Strukt\Money` is now self-contained and no longer extends
  `Strukt\ValueObject`; it has no runtime dependencies beyond PHP 8.2+.
- `strukt/bundle-book` and the book application now require `strukt/money`.

**Removed**

- `Strukt\Money` and its tests from `strukt/commons`.
- The Money section from the `strukt/commons` README.

**Tests**

- Money tests moved to `strukt4/money/tests/Unit/MoneyTest.php` and pass.
- The remaining `strukt4/commons` test suite passes.

**Public API impact**

- `Strukt\Money` keeps its existing public methods and behavior.
- `Strukt\Money` is no longer an instance of `Strukt\ValueObject`.
